RESEARCH NOTES

What is validated today?+

A synthetic, bias-free Linear → ReLU → Linear expert layer. Custom Triton execution on the NVIDIA A40 in FP32, FP16, and BF16; custom WGSL execution on the AMD RX 6800 in FP32. CPU references, a route compiler, a benchmark harness, and downloadable evidence. Inspect all 96 NVIDIA comparisons.

How fair is the benchmark?+

All four NVIDIA backends use identical GPU inputs and weights. CUDA is synchronized around each wall-clock sample. Initial compilation is outside timing. The fastest PyTorch variant is grouped PyTorch, so it is the headline comparison. Each workload has 30 samples, but this is one session with a fixed backend order—not a statistical claim across machines.

Where does the project stop?+

This release is an experimental single-layer runtime. Pretrained-model integration, real-model routing traces, distributed experts, training, capacity limits, and full text generation are future work. The browser visualization is an explanation of grouping, not a live performance test.

Can I reproduce the results?+

Yes. The repository includes the source bundle builder, GPU environment checks, a mandatory numerical gate, eight workload presets, and result archiving. The report records Python 3.12.3, PyTorch 2.8.0+cu128, Triton 3.4.0, and the A40 driver. Follow the remote harness guide ↗
